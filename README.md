# **Katalon PetStore Web Automation**



**Project Description** 
This project contains web automation testing for the JPetStore application using Katalon Studio.

The objective is to validate the main functionalities of the application, including authentication, product search, and shopping cart management.



**Tools and Technologies :**

* Katalon Studio
* Groovy
* XPath
* Data-Driven Testing (DTT)
* Git and GitHub



**How to Run** 

1. Clone or download this repository.
2. Open the project in Katalon Studio.
3. Configure the application URL and test data if required.
4. Open the relevant Test Suite.
5. Select the appropriate execution profile and browser.
6. Click **Run** to execute the test cases.
7. Review the execution results in Katalon Studio.



**Test Cases :**
The project covers the following functionalities:

1. Login
* Verify login functionality using valid credentials.
* Validate login behavior with invalid credentials



2. Logout
* Verify that users can log out successfully.



3. Product Search
* Verify that users can search for products.
* Validate the search results.



4. Shopping Cart
* Add a pet product to the shopping cart.
* Update the product quantity in the shopping cart.
* Remove a product from the shopping cart.



**Test Coverage**

* User authentication: Login and Logout
* Product search functionality
* Shopping cart operations:

  * Add product to cart
  * Update product quantity
  * Remove product from cart



**Security**

* Do not commit passwords, tokens, API keys, or other sensitive information.
* Use test data or local configuration for credentials.
* Review files before pushing them to GitHub.
